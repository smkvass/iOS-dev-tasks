# Music Player 
A simple music player app built with Swift and UIKit.

## About the Project
This project was created as part of iOS development coursework. 
It demonstrates building a music player interface using UIKit, UIStackView, and Auto Layout.

## Technologies
- Swift
- UIKit
- UIStackView
- Auto Layout
- Xcode

## Project Structure
- `AppDelegate.swift` — application lifecycle
- `SceneDelegate.swift` — scene configuration
- `ViewController.swift` — main screen logic
- `Assets.xcassets` — app images and assets
