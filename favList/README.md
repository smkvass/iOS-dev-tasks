# Favorites Navigator — My Movies

**Student:** Saya Smakova  
**Theme:** Favorite Movies  
**Platform:** iOS  
**Framework:** UIKit, Swift

## About the Project
My Movies is an iOS application that displays a collection of my 22 favorite movies. Users can browse the movie list and select any movie to view its details.

Each movie includes a poster, title, subtitle, rating from 0 to 5 stars, and a short description.

The application is built using UIKit and Storyboard. It uses a UITableView to display movies and a UINavigationController to navigate between the list and detail screens.

## Features
- Displays 22 favorite movies.
- Custom UITableViewCell with movie posters and titles.
- Navigation to a detailed movie screen.
- Movie information passed using `prepare(for:sender:)`.
- Ratings displayed with SF Symbols.
- Custom App Icon.
- Custom Launch Screen.
